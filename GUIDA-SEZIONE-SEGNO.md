# Sezione Segno vivo

La vecchia mascotte animata è stata rimossa.

- **HTML:** `index.html` — `<div id="inkExperience">`
- **CSS:** `css/ink-lab.css`
- **JavaScript:** `js/ink-lab.js`

La grafica è realizzata con SVG vettoriali, senza immagini raster, GIF, video o dipendenze esterne.

Per personalizzarla, modifica i tracciati e le forme SVG in `index.html` e le traiettorie `modes` in `js/ink-lab.js`.

La versione precedente del Portfolio a schede senza cornici è preservata in `css/portfolio-classico.css`.

In GitHub Pages i file vanno caricati mantenendo intatte le cartelle `assets/`, `css/`, `js/` e `documenti/`.
