# Calcolatori Elettronici — Teoria (primo anno)

La materia **Calcolatori Elettronici** è stata inserita in Università → **1° anno**.
All'interno della materia ci sono 14 PDF originali suddivisi sotto **Teoria**, ordinati
per numero di capitolo, con pulsanti «Apri» e «Scarica» e ricerca per argomento.

Percorso: `studio.html?anno=1#subjects` → Calcolatori Elettronici → `materia.html?id=calcolatori-elettronici`.

Il materiale già presente di Misure per l'Ingegneria dell'Informazione, terzo anno,
non è stato modificato.

Per pubblicare su GitHub Pages, carica **tutti** i file dello ZIP nella radice del repository,
comprese le nuove risorse dentro `assets/media/studio/1-anno/calcolatori-elettronici/`.
Verifica prima che siano presenti le autorizzazioni necessarie alla condivisione pubblica.
