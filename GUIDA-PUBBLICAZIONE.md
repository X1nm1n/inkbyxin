# Pubblicare il nuovo XIN Portfolio

1. Estrai lo ZIP e apri la cartella con PyCharm.
2. Crea un repository GitHub e carica tutti i file nella **radice**.
3. In GitHub, `Settings > Pages > Deploy from a branch > main > /(root) > Save`.
4. Aspetta che GitHub Pages completi il deployment e apri l'indirizzo `https://TUO-USERNAME.github.io/NOME-REPO/`.
5. Invia un primo test del modulo e **conferma l'email FormSubmit**; verifica con un secondo invio.
6. Per cambiare foto e contenuti modifica `js/projects.js`. Per aggiungere materie modifica `js/materie.js` e inserisci i PDF nelle cartelle corrette.
7. Esegui Commit/Push da PyCharm per aggiornare il sito.

**Ricorda:** il logo è già impostato in tutti i file principali. Non pubblicare liberatorie firmate, informazioni di contatto private dei clienti, contenuti universitari di terzi o foto di persone senza i necessari diritti e autorizzazioni.
